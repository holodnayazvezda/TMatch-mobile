# Tmatch

`Tmatch` это Android-приложение, построенное на Kotlin, Jetpack Compose, Koin и Ktor.

## Структура проекта

- `app` — точка входа приложения и сборка зависимостей.
- `api/*` — контракты домена и навигации.
- `feature/*` — реализация пользовательских фич.
- `data/tmatch_api` — работа с backend API и локальным хранением.
- `common/ui` — общие UI-компоненты и тема.
