# Tmatch: тестовые сценарии

Дата подготовки: 2026-03-17

## Назначение документа

Документ описывает ручные тестовые сценарии для пользовательских потоков приложения `Tmatch` в формате:

- входные данные / предусловия
- действие
- ожидание
- факт
- итог прогона

Сценарии составлены по текущему коду проекта. Автоматические подтверждения из unit/UI tests указаны отдельно. Поля `Факт`, `Скринкаст`, `Итог` заполняются после фактического ручного прогона на устройстве.

## Артефакты к каждому сценарию

- Скринкаст или запись экрана
- Дата и устройство прогона
- Факт: что реально произошло
- Итог: `PASS` / `FAIL`

## Среда прогона

- Android debug build
- Backend с актуальным `API_BASE_URL`
- Доступ в интернет для online-сценариев
- Для сценариев с push: Firebase-конфигурация и устройство с Google Play Services
- Для сценариев debug panel: debug-сборка

## Сводка автопроверок

- `./gradlew :data:tmatch_api:testDebugUnitTest :feature:auth:testDebugUnitTest :feature:profile:testDebugUnitTest :feature:matching:testDebugUnitTest :feature:chats:testDebugUnitTest :app:testDebugUnitTest` выполнен успешно 2026-03-17
- Unit-тесты подтверждают стартовую навигацию, auth/profile gateway-контракты, создание account/dating profile, matching feed и targeting preferences, открытие чата, отправку сообщения, список чатов и регистрацию FCM token
- UI test подтверждает переход с transition-card к рекомендациям свайпом
- Debug logs screen, push-отображение системного уведомления и websocket-degrade path всё ещё требуют ручного smoke-run

## Критический путь

Основной пользовательский маршрут:

1. Вход или регистрация
2. Заполнение базового профиля
3. Переход в ленту matching
4. Просмотр карточек и действие like/dislike/block
5. Переход в профиль пользователя
6. Переход в список чатов
7. Открытие чата и отправка сообщения

## Чек-лист перед внешним чтением документа

- Все сценарии из основного маршрута имеют свежий ручной прогон
- Для каждого сценария заполнены `Факт`, `Скринкаст`, `Итог`
- Есть отдельный прогон offline / unauthorized / debug overrides
- Есть минимум один прогон websocket и один прогон push
- Приложены записи не только happy path, но и краевых сценариев
